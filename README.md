# 

\# 概述

基于 STM32F103 的低成本四足机器人原型，定位为灾后与危险环境先期侦察的验证平台。当前版本完成从指令到舵机输出的完整平地行走链路，并接入蓝牙遥操作、手势指令、超声波避障与 OLED 状态显示；自主导航、姿态闭环与远程图像回传尚未实现。



\## 功能



\- 四足 12 路舵机：站立、前进、后退、左右平移、左右转向、踏步

\- 逆运动学（IK）步态生成，步幅与抬脚高度可调

\- FreeRTOS 多任务调度

\- 蓝牙无线指令与手势指令

\- 超声波测距避障

\- OLED 运行状态显示



\## 控制链路



状态机（指令解析与模式切换）→ 步态（足端轨迹）→ 逆运动学（足端坐标转关节角）→ 舵机控制（PWM 输出与平滑滤波）。蓝牙、超声波、OLED 作为外设接入上述链路。



\## 当前状态



平地行走已稳定。本版本降低默认步幅与抬脚高度、采用更柔和的步态相位曲线并对舵机输出滤波，前进、后退与右转的动作更清楚。坡面与碎石地形、自主导航、远程回传未实现。
